Files and sheets

Every tab is a sheet, every sheet is part of a file, and the tabs say which.

Files and sheets

A file - .hsk - holds one sheet, or several: a floor plan and its details, say, kept together. Each sheet has its own geometry, view and scale. Along the top, each sheet is a tab:

  • A file of one sheet shows the file's name - shop.
  • A file of several shows the file and the sheet - house: Ground floor, house: Upstairs - and its tabs sit close together, with a wider gap before the next file.
  • A drawing not saved yet is Untitled 1, Untitled 2...
  • A star - shop * - is work not saved yet. Every tab of the file shows it.

Ctrl+Tab steps to the next tab. /clear empties the sheet in front and keeps it. /sheet adds a sheet to this file, /new starts a new drawing.

Starting

The program starts on an empty drawing, Untitled 1. It does not open the last drawing by itself - Open Recent is one click away. Opening a file straight away replaces that empty drawing, as long as nothing has been drawn on it.

Saving

Saving writes the whole file - every sheet of it - in one go, and only once it is all written does it take the old file's place, so a full disk or a pulled stick leaves the old file whole. A file can be open in one tab group only: Save As onto a file open in another tab is refused.

The file is Heck - the drawing written as text you can read: a block for each sheet, a line or a block for each thing, lengths in feet and inches. You can read it, diff it, and keep it in version control. Nothing in it is compressed or binary. Files saved by a version before 30 September - a line of numbers per thing - still open, and are Heck the next time they are saved.

Closing

Closing a file - the cross on its tab, Ctrl+W, or Close This File - closes every sheet of it. If it has changes it asks first: Save, Don't save, or Cancel. A drawing never saved, with nothing on it, goes without a word. Closing the last file leaves a new empty drawing.

Closing the program asks the same about each file with changes, one after another; Cancel at any of them keeps the program open. Don't save means it: nothing comes back next time.

Moving work between sheets

Ctrl+C copies what is picked, Ctrl+X cuts it, Ctrl+V pastes. The paste arrives on the cursor and a click puts it down, so you choose where it lands rather than finding out.

It works across sheets, and that is the point of it: draw a fitting on one sheet, copy it, and put it into the assembly on another. A pasted solid is its own solid - push a face on the copy and the original does not move.

Through an update

When the program updates itself it has to stop and start again, and it does not make you deal with that. Everything open is written out first - every file and its sheets, which tab you were on, and which files had unsaved work - and put back afterwards exactly as it was, still marked unsaved if it was unsaved.

When it does not close properly

While a file has changes not saved, a copy of the work is written beside the program every few seconds. Close the program properly and the copy is thrown away - it is only there in case it goes down: a crash, a power cut, a kill. Then the next start asks: Recover them brings every drawing back as the file it was, with its changes still marked unsaved, so Save writes it where it belongs; Start without them starts empty and keeps the copy beside the settings as heckers-sketch-draft-not-recovered.hsk, which can be opened.

Undo

Ctrl+Z and Ctrl+Y, as far back as you like. Undo covers the geometry, not the view - spinning the model is not something to undo.
