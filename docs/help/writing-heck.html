Writing Heck

The whole language on one page - for typing a drawing, or writing one from another program.

Heck says what a drawing is. This page is all of it: the words, the marks, every kind of thing and what it takes, what the program works out for itself, and what it writes back. Every example here is read by the program as it stands. Paste one into /source and press Apply to see it.

A file

A header, then a sheet block for each sheet:

HeckersSketch 2
units = ft in

// a comment here belongs to the first sheet
sheet 'Shop'
  scale = '1/4"'
  snap = '1/16"'
  view = 3d
  box Bench = 0 east, 0 north, 0 up; 6' east, 2' north, 3' up
end

The sheet's settings come first and are all optional: units, scale, snap, view (plan, iso or 3d), camera, cut, and the sheet's own ink, width and sides - the defaults for everything on it. Text pasted into /source without a header or a sheet is read as one sheet.

The one rule

A line with = is complete. A line without one opens a block, and end closes it. That is the whole block grammar. Every thing has both forms, and you may write either:

line = a to b

line Rafter
  points = a to b
  ink = red
  width = 2
end

A list too long for a line opens a bracket after the = and runs to the line that closes it:

face = (
  p1 p2 p3 p4 p5 p6 p7 p8
  p9 p10 p11 p12
)

A reader skips any block or line it does not know, so a newer drawing still opens in an older program. There is no begin (one is let pass if typed), and nothing in a file ever runs.

Words and marks

  • Case does not matter; the program writes words in lower case.
  • Spaces do not matter. Indentation is for the eye; blank lines go anywhere.
  • Comments are // to the end of the line or { in braces }. A comment above a thing, or at the end of its line, stays with that thing through every save. The program's own { facing up } notes on faces are never read as anything.
  • Names: a letter, then letters, digits or _ - a, p272, LegSW. Not x, y or z. A name with spaces goes in quotes: group 'Left turbine'. Names are not case sensitive.
  • Text is in single quotes, a quote inside doubled: 'the fitter''s bracket'.
  • A ' straight after a digit is feet; anywhere else it opens text. Where quote marks are a nuisance there are words: 4ft, 6in, 90deg.
  • True and false are true and false (1 and 0 are read too); nothing is none.
  • Colors are #RRGGBB, or black white gray red orange yellow green blue purple brown.

  • Fractions go down to sixty-fourths. Anything else is written as a decimal in full, 2.843721934", and never rounded to look friendlier than it is.
  • Sums go anywhere a length goes: 4' + 2", (Width - 1') / 2. The program writes back the answer.
  • Constants name numbers for the sums below them: 
    const
  Width = 4'
  Gap = (Width - 1') / 2
end

Places and steps

A place says all three directions, always: east or west, north or south, up or down. No number in a place is ever negative - the word carries the way. 0 up is on the floor.

2' east, 3' north, 0 up
3' west, 2' south, 6" down
x 2' y 3' z 0                  the letters are read too

A step says only what changes: 4' east, or 3" east, 2" up.

Wherever a place is wanted it may be a place, a name, or a name and a step: a, a + 1" up. In a list, places are joined with to, and + and a step means "from the one before", so a list is a walk:

face = 0 east, 0 north, 0 up to + 4' east to + 4' north to + 4' west

A list of names needs only spaces: face = a b c d, and a..h or ra1..ra24 is every name from one to the other.

Points and rings

A points block names places. Everything in the same block and the blocks inside it can use them, which is what makes a corner shared by three faces one corner:

points
  a = 0 east, 0 north, 0 up
  b = a + 4' east
  c = b + 4' north
  d = a + 4' north
end

b = a + 4' east is how b's place is written down, not a link: change the 4' and b moves, and so does whatever was written from it.

A ring is corners spaced evenly round a circle, said once. Its corners are its name and a number, counted anticlockwise seen from the side it faces:

points
  ring ra
    center = 2' east, 2' north, 2' up
    radius = 1'
    sides = 24
    facing = up
    starts = 15deg       where corner 1 is; 0 if left out
  end
end
face = ra1..ra24

facing is the way a flat thing looks: up, down, east, west, north, south; one that leans, up, leaning 30° toward east; or three numbers, 0.5 east, 0.5 north, 0.7071 up. starts is measured from east for a thing facing up or down, otherwise from its level line.

Faces

Faces are what closed lines become. Twelve lines that close a cube give you its six faces, so a plain face is never written. Write a face only when something about it is not automatic: it is painted, it has a hole the lines would not cut, or it faces the other way.

  • A face's outline goes round anticlockwise seen from its front - the side paint is on. A hole goes the other way. In a solid, faces turn away from the solid's middle.
  • noface is a loop of lines that is not a face: an open top, a window. It is how you leave something open, instead of drawing a face and rubbing it out.
  • A circle on a face cuts it into the face with a hole and a disk in the hole. noface = Hole takes the disk away and leaves the opening. A hole right through a solid is a bore.
  • paint = none on a face in a painted solid leaves that one face unpainted.

Solids

A solid is one piece: push/pull moves only its own geometry, and what is drawn against it does not fuse into it. It names its corners, then gives its lines, and faces only where needed:

solid Wedge
  paint = gray
  points
    a = 5' east, 0 north, 0 up
    b = a + 1' east
    c = a + 1' north
    d = a + 1' up
  end
  line = a to b
  line = b to c
  line = c to a
  line = a to d
  line = b to d
  line = c to d
end

box and pull are solids in one line. A box is a rectangle pulled up; a pull is any flat outline - corners, or a circle by name - moved a step. The program writes a solid back as a box or a pull while it still is exactly one, and as its corners and lines once it has been changed.

Groups

A group keeps a piece to itself: it is picked, moved, hidden and locked as one thing, its geometry never joins its neighbor's, and groups go inside groups for an assembly. Names given in a group's points are its own.

group 'Hangers'
  locked = true
  jig = 'hangers' with Count = 6, Spacing = 16"
  ...
end

jig names a program that writes the group's contents (see Jigs); data is a block a tool keeps for itself, kept as it is.

What comes back

The program reads Heck into a drawing and writes the drawing out again - on every save, and in /source as you work. What it keeps and what it puts its own way:

  • Kept: every name you gave - things, groups, circles and a solid's corners - and every comment, with the thing it was written with.
  • Its own way: the order of things, the spacing, which earlier corner a point is written from, and the short or block form of each thing. A comment that was inside a block goes above the block.
  • Folded: lines that are exactly a box, a pull or a rect come back as one; a face the lines already make is left out.
  • Named for you: a corner you did not name, by where it stands - floor1, top1 - and an unnamed circle as c1. Lines that belong to no solid are written with their places, not names.

A mistake stops the whole Apply, marked on its line with what was expected; nothing on the sheet changes until the text reads.

Examples

A chest with its lid propped open on the back edge, and a post and a plate beside it:

// a chest: a box, and its lid swung up 30 degrees on the back edge
group 'Chest'
  box Body
    at = 0 east, 0 north, 0 up
    size = 3' east, 2' north, 1' 6" up
    paint = brown
  end
  // the front edge has swung up: 2' cos 30 = 20.7846" back,
  // 2' sin 30 = 12" up
  solid Lid
    paint = brown
    points
      h1 = 0 east, 2' north, 1' 6" up
      h2 = h1 + 3' east
      f1 = h1 + 20.7846" south, 12" up
      f2 = f1 + 3' east
    end
    line = h1 to h2
    line = h2 to f2
    line = f2 to f1
    line = f1 to h1
  end
end
// a cylinder is a pulled circle; a circle on a box's top cuts it
group 'Post and plate'
  circle Post = 6' east, 1' north, 0 up; 3"
  pull Column = Post; 3' up
  circle Hole = 9' east, 1' north, 2" up; 3"
  box Plate = 8' east, 0 north, 0 up; 2' east, 2' north, 2" up
end

A painted panel with a square window in it:

face Panel
  points = 20' east, 0 north, 0 up to + 4' east to + 4' north to + 4' west
  hole = 21' east, 1' north, 0 up to + 1' north to + 1' east to + 1' south
  paint = #3366CC
end

A checklist for writing a model

  1. A group for each part, groups inside groups for an assembly.
  2. A name on each part you will want to talk about later, and a comment above it saying what it is.
  3. Name the corners of a solid you write by hand; the names are kept, so a later change can say which corner it means.
  4. Lines, not faces. Faces come from closed lines. Write a face only for paint, a hole, or a way round; use noface for what is open.
  5. The shorthand where it fits: box for blocks, pull for a profile pushed some distance, circle with pull for round things.
  6. Places exact: every corner of a face on one flat plane, and shared corners written once, by name, so they meet.
  7. Read it back. Paste it into /source and press Apply; a mistake is marked on its line.
